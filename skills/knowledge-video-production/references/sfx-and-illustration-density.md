# 音效与插图密度规范

用于整片分镜、素材规划、声音设计和最终验收。以下数字是本地中文科普的可覆盖规划起点，不是行业标准、自动质量评分或逐分钟配额。实际旁白、证据可读性及用户本次要求优先；偏离范围时在现有分镜/验收记录简述理由，由agent自主调整，不增加审批。

所有每分钟平均值均按正文时长计算：包含开场提问与结论，排除纯片尾署名/交付板；只统计正文内首次引入的插图组和起音的SFX事件。以下“全片平均”指完整正文的平均，不用片尾稀释密度。

## 一、音效：为可见事件提供听觉反馈

### 事件选择与密度

音效优先用于对象接触/落纸、关键传递到达、机制状态改变、重要揭示或有意义的段落边界。每个音效写清对应事件和作用；移除后既不损失动作反馈、注意引导也不影响节奏的声音，可省略。

| 项目 | 默认规划与复查规则 |
|---|---|
| 点状音效 | 全片平均每分钟4–10个事件，3分钟约12–30个；不是40镜就配40声，也不是每分钟必须补到4声 |
| 局部上限提醒 | 任意10秒内超过3个独立音效起音时复查是否抢人声；确有连续机械动作或短促节奏串可保留，记录作用 |
| 安静区 | 每个解释段保留至少一个完整句或稳定阅读区不新增点状SFX；不强制暂停旁白、音乐或真实环境声 |
| 同时发生 | 通常一个主音效事件；多层合成同一次落纸算一个事件，避免无关声源叠加 |
| 连续环境声 | 单独标注起止和用途，不计入点状事件数；不能靠铺满环境声绕过留白与可懂度检查 |

同一声源连续重触发按各次起音计数；一个复合撞击的木声、低频和混响合为一事件。重复流程可只强调首次或关键变化，不为每个字、标签、节点、箭头或切镜配提示音。

### 声音家族与禁用情形

全片先选2–4类相容材质，例如纸片/轻木、柔和空气、克制电子反馈；每段通常用其中1–2类，复用已授权素材并微调力度。不要无理由每场换声音语言。

- 纸片入场：短而轻的纸/木质接触；无须每张纸都响。
- 传递与到达：轻微移动或到达反馈，按知识任务选择其一或组合；不能让声音先于画面到达。
- 机制变化：短促且易辨的反馈；示意声音不得宣称为设备真实提示。
- 重点揭示/转折：可使用一次克制强调或短暂减薄配乐，不默认重低音撞击。
- 数据、引用与复杂证据阅读：默认少音效；读数每跳一次、每行高亮不逐次发声。
- 无依据的故障警报、恐怖音、夸张成功/失败音、常规镜头的连续whoosh不作为默认，不用声音给事实添加情绪结论。

### 时序、混音与来源

在现有timeline的事件记录或等价声音表中写：event_id、scene_id/shot_id、触发动作、startFrame、durationFrames、asset_id、增益/声像、用途。资产来源、授权和文件指纹复用assets.json，不另建重复账本。首次规划允许暂定帧，真实动作锁定后更新。

声音主体对齐接触、到达或状态改变的实际帧；有预备段的音效可提前，但其重音仍对齐事件。每个文件检查起止是否截断、循环接缝和尾响，时序改变后重查。

以正常播放响度制作VO+MUSIC+SFX混合试听；人声出现时，音效先从比邻近旁白短时RMS低约8–14dB的增益起点试配（相同声道、相同约0.3–1秒窗口，不拿音效峰值与人声LUFS相减），再依据频段与实际听感调整。此范围不是响度通过门槛；短瞬态仍可能遮住辅音。优先减增益、错开关键术语或削减冲突频段，不自动抬高整段旁白。最终混音规格沿用[audio-and-timing](audio-and-timing.md)，不再设置冲突的母带目标。

制作开场、机制密集段、安静阅读段三个实际混合片段；不足三类则覆盖实际存在的类型。检查术语清晰、音效不刺耳、事件对应、家族一致及留白。分别标注数值检查和实际试听；工具无法听音时保留“待试听”，不能凭波形或目标滤镜声称声音合格。保留独立SFX分轨；素材不可用时明确待补，不以空轨冒充已设计音效。

## 二、插图：覆盖讲解对象，保持有意义的变化

### 先分清计数对象

- **插图组**：服务于同一个视觉任务、可复用的一组场景/角色/实物剪贴/概念插画。完整场景算一组，其中多个cutout是图层数量；不能拆文件刷数量。
- **新插图组**：首次引入新的讲解对象、环境或有实质信息变化的组合。换色、裁切、平移、轻推近、换标签不算新组；复用旧素材组成能表达新关系的新画面可算新组，但不算新增生成资产。
- **插图覆盖率**：有承担解释作用的插图组可辨认地在场的时间并集÷正文时长。正文含开场提问与结论，排除纯片尾署名/交付板；多个插图同时在场不重复累计。纸纹、装饰小图标和角落吉祥物不计覆盖。
- 图表、地图、流程图、原始证据、真实UI/截图单独归类；它们可以完成视觉解释，但不冒充插图或生成资产。镜头数、信息组数、插图组数和生图次数分别记录。

### 默认规划范围

| 项目 | 默认与检查方式 |
|---|---|
| 新插图组引入频率 | 全片平均每分钟4–8组；3分钟约12–24组。允许跨镜复用，不要求每组重新生图 |
| 插图时间覆盖 | 混合纸面科普以正文40%–70%为初始范围；其余可由图表、机制、地图、证据和UI承担。该范围不要求插图在40%–70%的面积内 |
| 有意义画面覆盖 | 每个正文讲解段都有对象/关系/数据/证据等有效视觉支持；纯文字问句、转折或结论可短暂使用，写明用途 |
| 单镜物件负荷 | 通常1个主插图组配0–2个辅助物件/组，再按中/高信息密度组织；必要标签不按插图计。复杂组合先检查阅读顺序，不按物件上限删去关键机制 |
| 更新触发 | 同一插图连续使用超过约12秒、连续3镜仅裁切/漂移/换字，或正文连续约10秒只有大标题/抽象装饰时，触发内容复查，不直接判失败 |

图表/证据主导、抽象机制或人物叙事可偏离上述范围：在分镜摘要写出段落及选择理由；有充分解释变化、阅读需求即可保留。不能为达到插图指标插入无关生活照，也不能因图表很多就省略观众理解所需的具体对象。中/高信息密度的2–3/4–6信息组仍按[storyboard-design](storyboard-design.md)执行，不能把它改读为每镜要生成2–6张插画。

### 复用、变体与来源

先规划主角/核心设备/场景基准，复用同一资产身份、视角和尺度规则；按动作拆独立图层。优先通过新关系、局部细节、状态与观察尺度推进解释，再判断是否需要新生成资产。新增变化应能回答“观众因此多理解了什么”。

生成插图仅表达场景或机制示意；真实事件、官方界面、测量和来源证据使用真实材料并保留来源。语义准确的地图/数据/标签继续代码制作。记录asset_id、复用镜头、新组用途及来源限制；原始素材与合成画面分开保存。

## 三、统一验收与记录

在已有分镜表增加“视觉类型、插图组ID/是否首次、有效时段、SFX事件或无音效理由”，不要求逐镜重复长说明；同类无音效镜头可在段落级写一次理由。汇总在既有evidence/production记录中保留：正文时长、新组数、覆盖时长/比例、点状SFX事件数与每分钟平均值、密集窗口、偏离范围原因、当前版本预览/试听路径及未完成事项。

先按分镜时间估算，真实配音与帧时间线锁定后复算。手工统计注明手工，不声称已有自动覆盖率检测器。指标在范围内仍需逐镜看图、逐段看动态与混合试听；范围外只触发复查，误导因果、无关填充、素材不可读或音效遮住关键术语才是必须修正的内容问题。沿用[视觉验收契约](visual-acceptance-contract.md)和现有技术检查。

例如：3分钟40镜，规划15个新插图组，插图承担解释的并集为96秒（53%），18个点状SFX事件（6次/分钟）；图表证据占主导的一分钟可以只有1个新组和2次音效。此例仅演示统计口径，不是每支片的固定配置或已验证成片。
