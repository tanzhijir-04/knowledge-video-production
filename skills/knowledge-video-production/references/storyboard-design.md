# 分镜设计与验收：更多有效镜头，可选中/高信息密度

用于每次新建或修改知识视频分镜。保持已批准的论点、证据和用户规格；支持生图、HTML/CSS/SVG或混合分镜。分镜既要说明镜头如何推进信息，也要有实际可查看的视觉预览。

每次设计或修改分镜同时读取[分镜连续性与剪辑](storyboard-continuity.md)。其中已融入create-storyboard的镜头卡、连续性、承接和剪辑边界方法，并适配本用户的HyperFrames、密度选择及视觉契约；本地文件足够执行，不依赖远程仓库运行时可用。

## 1. 分开设置镜头节奏与画面信息密度

插图密度另按[音效与插图密度规范](sfx-and-illustration-density.md)规划新插图组、有效覆盖时长与复用；信息组不是插图数量，镜头多不代表需要更多生图。分镜同时标注视觉类型、插图组及有意义的SFX事件，音效留白可按段落记录。

同时按[连贯动效](motion-continuity.md)设计段内视觉主线、动静节拍和承接物；新片可比较简短视觉思路，已批准设计或局部修改直接沿用，不新增用户审批。OneTake产品短片的固定静止占比、镜长倍数和全片一镜到底不作为科普分镜硬要求。

在BRIEF.md或production.json中记录画面信息密度（中/高）、计划时长、目标镜头范围及实际镜头数，沿用已有配置结构。用户已选的值持续有效，不重复询问。首次规划可简短询问偏好并继续拆稿；未指定时默认中密度并说明，可由用户改为高。

| 选项 | 画面组织 | 典型内容组合 |
|---|---|---|
| 中密度（默认） | 一个明确主关系，通常有2–3个有意义的信息组；主次清楚，保留阅读空间 | 主体与机制图；证据局部与解释；两个对象及共同对照基准 |
| 高密度 | 一个主论点下通常有4–6个有组织的信息组，按主—次—补充分层；可逐步揭示，必要参照保留 | 主机制、局部细节、对照、证据及关键条件共同构成解释 |

信息组是可独立理解的对象、证据或关系，不按DOM数量计数。上述组数是构图起点，不是硬配额；一个详细图解可含多个信息组。标题、纸纹、阴影、无意义图标、旁白复写不算新增信息。高密度不等于把更多小字同时堆满画面，也不等于每个镜头都要复杂。少量低密度镜头可用于提问、转折或结论，但不能无说明地让全片回到“大标题+一张图”。

用户可独立调整镜头节奏和密度，例如“镜头更多，中密度”或“正常节奏，高密度”。高密度若在小图中不可读，应重新分组、分层揭示或拆镜，不能偷偷降成低密度，也不能缩小字体硬塞。

## 2. 镜头数量与拆镜

- **场景**是工程组织或叙事段落；**镜头**是具有独立视觉任务、构图/视点与时间区间的观看单元；**动作节拍**是镜头内部的信息变化。一个场景可以包含多个镜头，长镜头也可以有多个节拍。
- 每分钟约10–15个有效镜头作为新片的初始规划范围：3分钟约30–45镜，4分钟约40–60镜，5分钟约50–75镜。此为本用户的制作起点，不是行业规律或验收硬配额；不可用重复镜头凑数。
- 通常先按4–6秒一个观看单元粗排，再依信息难度、字幕外的图解阅读时间及真实配音调整。证据阅读、复杂机制可更长；短反应镜头可更短。较长镜头逐一检查是否有充分的信息推进，只有照片漂移、标签换字或纹理运动不能算持续解释。
- 换论点、换对象、从整体转细节、从现象转机制、引入证据/反例、进入对照、展示后果，都应考虑拆镜。不是一句旁白机械切一次，也不是一个自然段只配一张图。
- 只有换标签、换背景颜色、把同一图片轻微推近或把一张图导出几份，不算新增有效镜头。改变观察尺度若揭示新细节且支持新视觉任务，可以算新镜头。
- 保留同一对象、方向、色彩含义或共同基准作为跨镜承接；允许有意重置，但要让观众知道进入了新场景。不能为了数量频繁换画面而丢失解释链。

最终数量明显低于初始范围时，主动重新检查是否拆镜不足；有阅读/证据理由可保留并记录，不要求用户逐镜批准。时长尚未有真实配音时明确数量和时间均为暂定，配音后重排并检查阅读余量。

## 3. 从脚本生成可执行分镜

先将批准稿拆成“问题/对象 → 机制或变化 → 证据/对照 → 条件/结果”等实际知识变化，不要求所有段落使用同一顺序。为每个变化选择整体、局部、关系图、证据页、对照或过程视图，避免长时间复用同一构图。

每镜在已有分镜表中记录：稳定shot_id、所属scene_id、对应旁白/触发词、预计起止与时长、视觉任务、主要关系、构图与视点、信息组及阅读顺序、独立图层、入口/关键动作/终态、与相邻镜头的承接、实际预览路径。来源沿用证据账本。无需新增并行的一套台账。

按连续性规范补齐每镜接收状态、交出状态、参考资产、切入/切出设计和失败替代方案；生图之前先完成相邻边界表。每镜制作板以实际图像表示开始、关键动作和结束状态，精确文字和元数据由可控布局工具合成，整片联系表不能替代逐镜预览。

先做开场、最复杂机制、最密集对照等代表镜头，验证密度和画风，再扩展全片。正式分镜覆盖每一镜，动作内含重要状态变化时补关键状态图；不能用几张代表图冒充全片分镜。

生成图可探索整体构图，但精确中文、数字和关系必须有代码排版或合成后的真实预览用于验收。占位素材须标明；未替换且会影响尺度/遮挡时不得声称正式素材的布局已通过。生图文字看似正确不等于最终字体、断行、连线已验证。

## 4. 每次分镜制作都执行视觉审查

采用[视觉验收契约](visual-acceptance-contract.md)和[布局检查与纠正闭环](layout-contract-and-qa.md)，将“每场检查”细化到每一镜，复用同一套证据与纠错记录。

1. **逐镜看图**：实际打开最终画幅的每镜预览，分别看原生分辨率与约540px宽小图。检查层级、对齐、分组、文字、图形关系、密度和构图；没有看到图就不能声称完成视觉审查。
2. **全片看节奏与承接**：查看按顺序排列的联系表/分镜板及预计时长；逐段对照旁白，检查镜头数量、视觉信息推进、密度是否符合中/高选择、相邻镜头是否重复或跳脱。按边界表将前镜结束图与后镜开始图并排检查，确认对象、方向、阅读落点与声音承接；刻意重置有明确理由。联系表不代替逐镜原图。
3. **纠正并复查**：列出具体shot_id、问题、修改和修正后图路径。密度不足时补充有解释价值的内容或拆出新视觉任务；太挤则重分组/逐步揭示/拆镜。重新查看修改后的实际画面并检查相邻承接。
4. **区分静态与动态**：静态分镜只能证明构图和关系；依赖运动才能成立的关键关系制作短预览再审查。尚未制作的动作标记“待动态验证”，不以文案说明代替运动证据。
5. **变更触发复查**：每次改分镜都重查修改镜头与相邻镜头；字体、共享版式、画幅或密度切换影响的所有镜头都重查。未变化且输入一致的证据可复用，不需要无意义重做全片。

在evidence/layout-review.md或等价现有记录中，以shot_id建立检查索引，注明storyboard阶段、密度选择、实际数量/总长、预览与当前版本；已通过镜头可一行记录，问题镜头留前后对照。未看过的镜头、未纠正的阻断项保留“待视觉验收”。AI审查与用户观看分别标注，不强加逐镜审批。

## 完成条件

分镜交付必须有：完整镜头卡及逐镜制作板、相邻镜头承接/剪辑边界表、复用对象的连续性约束、镜头数量与时长概览、明确的中/高密度选择、逐镜和逐边界审查覆盖及已闭环的静态问题。动态验证状态单独标注；只要求静态分镜时可在交付说明中保留待动态验证事项，不虚称已完成动画，也不擅自扩为全片制作。
