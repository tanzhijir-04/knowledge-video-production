# 视频视觉验收契约 v1

本契约约束每次视频制作或修改后的最终画面，具体构图和风格仍可自由选择。按[布局检查与纠正闭环](layout-contract-and-qa.md)执行检查、修正和复查；不等用户截图后才检查。

分镜阶段同样适用本契约：每次制作或修改分镜，都按[分镜设计与验收](storyboard-design.md)逐镜查看真实预览、纠正并复查。静态分镜只可通过静态视觉审查；动态稳定性须由实际运动预览验证，未实施时标记待动态验证，不伪称已通过。只要求分镜的任务不因此扩成全片制作。

## 通过标准

| 检查项 | 通过标准 | 不通过的典型情况 |
|---|---|---|
| 信息层级 | 第一眼能找到主信息，阅读顺序支持讲解 | 标题、装饰抢过解释主体；多个重点竞争 |
| 对齐 | 同组元素遵循明确的边线、中心线或基线 | 标签偏离对象；同排元素无理由高低不齐 |
| 间距与分组 | 组内联系明显，组间边界清楚 | 文字贴边；无意擦边；标签归属含糊 |
| 文字适配 | 字体正确、断行自然，关键文字在缩略图中仍可读 | 缺字、溢出、意外裁切、孤字成行；靠不断缩字解决拥挤 |
| 构图与密度 | 主体尺度支持理解，留白和密度有合理分布 | 主体过小；一处拥挤而另一处无理由空置 |
| 图形关系 | 对象的连接、指向、包含、对照和前后关系准确、可追踪；图形不暗示脚本未支持的因果、比例或归属 | 误连、方向含糊、交叉被误读为汇合、错误包含、比较尺度失真、遮挡关键关系、运动中关系漂移 |
| 动态稳定 | 入口、超调、移动、缩放和转场中关系保持正确 | 标签漂移、运动遮字、瞬间越界；只在终态排好 |
| 全片一致性 | 同类元素保持一致的字体层级、间距和图形语言 | 字号、线宽、强调方式无理由漂移 |
| 承诺风格可见 | 默认纸面方向按[材质契约](paper-materials.md)检查最终合成与动作，纸底、剪贴层次及印刷处理实际成立 | 只有奶油平底；纹理被不透明层遮住；仅个别插图有纸感；用源码或技术检查冒充风格验收 |

## 图形关系专项契约

每场只检查实际使用的关系，不为满足清单额外添加连线、框或箭头。先确定要表达的关系，再选择图形；图形本身不能增加原稿没有的结论。

| 关系 | 通过标准 | 检查与纠正 |
|---|---|---|
| 连接与流向 | 起点、终点、方向明确；分支可追踪；连接、传输、先后与因果不混用 | 沿每条路径从源到目标检查端口与箭头；误连先重排节点/通道，再调路径；不能只在错误路径上补箭头 |
| 指向与归属 | 每个标签、圈选、引线和状态标记有明确对象或范围 | 隐去解释性旁白后仍能判断标记属于谁；有歧义则靠近目标、缩小标记范围或增加短引线 |
| 包含与分组 | 容器、包围、接触与相邻关系符合真实归属 | 检查边框是否误包无关对象、成员是否被裁到外部；图例/标题不得因位置而被读为组内数据 |
| 对照与尺度 | 同类对象用可比较的基准；大小、长度、面积和位置不制造虚假的数量关系 | 定量图检查单位、零点/刻度与映射；示意物件可按构图调整，但不能借相对大小暗示不存在的差异 |
| 交叉与汇合 | 无关线交叉与真实节点汇合有可辨认的区别 | 优先减少交叉；必要时用桥接、断口或明确节点区分，并在小图确认；不能让重叠看起来像新增连接 |
| 前后与遮挡 | 叠放顺序支持语义；必要的边界、端口和关系仍可辨认 | 检查可见轮廓而非只看矩形框；移开遮挡物或调整路径/层级，不能遮住错误端点后宣称连接正确 |
| 附着与运动 | 附件与目标共享坐标/变换，移动期间保留归属、连接及必要净距 | 检查入口、超调、交叉和相机极值；修共享几何或父子变换，不只补终态坐标；关系改变须是有意表达的事件 |

验收时先看实际画面，尝试读出“谁与谁是什么关系、方向或范围是什么”，再与本场脚本核对。读不出、存在两种互相冲突的合理解释，或读出的含义超出证据，均需纠正。最后沿每条关键路径/包含边界检查，并看同一关系的动态片段；原生帧与缩略图都应成立。

错误的方向、因果、归属、包含和定量尺度属于阻断问题，即使没有重叠、溢出也不能通过。单纯路径不够简洁但不影响理解时按“需要优化”处理，不把所有交叉或有意遮挡一概禁止。

## 问题如何处理

- **阻断验收**：影响阅读或造成错误理解，包括文字不可读、错归属、误连、意外遮挡或裁切。必须修正并复查。
- **需要优化**：层级、密度、间距或主体尺度不合理。必须做针对性调整，并查看前后对照。
- **允许保留**：有意的非对称、倾斜、出血、重叠。前提是实际可读、关系清楚。

不使用平均总分放行。一个阻断问题不能被其他项目的高分抵消。

## 每次制作必须留下的证据

1. **每场原生帧与约540px宽缩略图**：分别检查细节和整体阅读。
2. **关键动态片段**：检查最大超调、对象交叉、相机极值及转场，按实际存在的风险选择时点。
3. **纠错记录**：问题所在场景与时点、具体修改、修正后画面；没有发现问题的场景保留检查索引。
4. **变更复查**：字体、素材、布局或时序改变后，复查受影响场景及相邻转场。

程序负责几何测量，agent负责查看真实画面并自主纠正；普通内部审查不需要用户逐场批准。分别记录实际执行的程序测量、AI画面审查和用户观看，不能互相冒充；没有测量工具时如实记录未执行，不能伪称自动检查通过。

## 最终通过条件

所有场景完成检查，已发现的问题完成纠正与复查，证据对应当前版本。未完成时明确标记“待视觉验收”。技术解码或检查脚本通过不等于视觉通过。

本契约是制作与验收要求，不是已实现的自动检测器，也不保证永远没有遗漏。更新契约不能作为旧片已经修复的证据。
