# 字体与版式：用实际画面决定

用户反馈过字体不美观、排版不协调。重点检查字体与内容、图像、比例的关系；HyperFrames和VOX风格包本身不能保证审美。此规范服务编辑式科普，不把电影片头、网页卡片或英文营销模板当默认。

## 已确认的默认方向

用户选择以vox-style-animation为基准的纸面杂志拼贴。先读该skill：奶油纸面、油墨黑字、实物剪贴、局部半色调、黄色荧光笔与少量手绘批注，共同形成“印出来的”画面。不要再把现代极简或冷峻科技界面列为并列默认方向。

中文标题优先比较阿里普惠体真实粗字重形成的油墨感，说明文字用协调的常规/中等字重；思源宋体只在具体画面确实更合适时使用，英文使用Lato与Playfair Display Black，数字随实际版面选择协调字体。用途由agent/LLM自主决定，不预先锁定哪个用于标题或正文，不要求每片集齐所有家族。上游Archivo Black/Inter/Caveat、全大写和0.98行距不是中文排版指令。

以图片裁切、纸张叠放和尺度对照组织版面，重点字可用实体黄色标记扫入；偏转与硬投影主要服务剪贴物，精确数据和密集标签仍保持清楚的对齐。没有证据截图时不得把生成图装作真实档案；不要为了手工感给每张图加撕边、每行字加倾斜或让所有元素持续漂移。

## 先做少量可比较的画面

使用真实脚本做开场提问、机制解释、数据/物件对照三类代表帧；短片不含某类时用实际存在的复杂画面替代。同一内容做两种有明确差异的字体/版式方案，比较后选一套。已有已认可的视觉系统则沿用，只验证本次变化，不重复全套选型。

输出可查看的HTML或渲染图。生图负责构图探索，最终准确文字由代码排版。检查原生画幅与约540像素宽缩略图：第一眼能否看懂主关系？关键字和数字是否仍清楚？图片是否有解释作用？删掉装饰后信息是否更清晰？不能用几行ABC字体样张代替真实版面比较。

把选定方案写入项目frame.md：实际字体文件与字重、主次文字用途、设计坐标及字号、行距、字距、边距、对齐基准、色彩、三张代表帧路径和选择理由。不要写成只有“高级、精致、有设计感”的形容词。

## 字体选择与中英协调

- 中文优先阿里普惠体3、思源宋体CN；英文使用Lato与Playfair Display Black，非必须同时登场。先以一个主字体家族及其真实字重建立秩序，再判断是否需要第二家族。思源宋体用于确实需要的编辑语气，不为“高级”给每场强加宋体标题。
- Lato与Playfair Display Black的用途、字号、混排比例由agent/LLM根据场景决定；Playfair Display Black须加载Playfair Display真实900字重（静态或覆盖900的可变字体），不能用伪粗体模拟。D-DIN仅保留为旧工程或用户后续明确需要时的选择。中英混排比较实际字高、粗细和基线，同一行的中文、Latin、数字要用真实内容核对。
- 不用CSS伪粗体或scaleX压扁字形制造窄体。字距按字体和文字长度决定；中文正文不套英文标题的大幅负字距，长英文不强制全大写拉开。
- 明确本地@font-face与真实文件/字重，核对常用汉字、标点、英文和数字实际显示。字体文件未加载、缺字回退或英文字体别名映射都算未验收；不能只检查CSS声明。
- 本次用户明确指定的字体优先；如现有候选无法满足画面，提出具体替换理由或做可比较方案，不能无说明换字库或要求用户重新选一遍全部字体。

## 版式按信息关系组织

- 每场先确定观众要理解的一个主关系：路径、包含、先后、比例或对照。文字贴近所解释的对象；连接线、标记、距离都应表达这个关系。避免把画面变成居中大标题加三张卡片。
- 先确定主体占比和文字落点，再安排标题。说明文字服务图像，不能用巨型标题挤掉机制图。开场、机制图、证据页允许不同密度，不能所有镜头套同一模板。
- 一般保留主信息、解释标签、必要来源三层，用字号、真实字重和位置拉开层次；不是给每层都加底框、阴影、描边。只有影响理解的信息才应可读，不为填空加入英文小字、页码、章号。
- 明确共同边线、对象中心和基线。网格辅助对齐而非限制构图；边距和组内/组间间距要有可重复逻辑。视觉居中需考虑物件轮廓和文字重心，不能只信CSS边界框。
- 中文按语义主动断行，避免单字孤行、单位与数值拆开、标点落在行首。先缩短文案或重排，再考虑缩字号；不得以一味缩小解决溢出。长英文、中文与数字的边界单独检查。
- 色彩强调只指向当前论点。纹理、半色调和纸边不能损害小字、细线和照片轮廓；纸面风格不等于每处都脏、都倾斜。
- 不烧旁白字幕不等于底部必须留出巨大空白，也不等于删除必要图解标签。文字特效用于引导阅读和说明关系，不能掩盖静态布局问题。

## 扩展与审查

代表帧过关后才批量扩展版式与动效。每种新场景模板以及全片最密集、最长文本的帧都需实际查看；在最终宽高比下检查原生图和缩略图。检查转场中途的重叠、裁切、基线漂移，不能只看首尾。

记录具体问题、修正及修正后帧路径。例如“中文标签抢过实物主体；降低字重、移到对应接口并缩短两字”，不要只写“视觉审查通过”。自动溢出检查只能证明部分布局条件，不能证明审美。未生成真实视频或画面时，只能说规范已更新。
