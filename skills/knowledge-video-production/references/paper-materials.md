# 纸面拼贴材质与合成验收

默认 Vox 方向须在最终画面呈现“印在纸上、剪下再拼贴”的物质感。奶油纯色、黑字、黄色矩形只是配色，不能独立证明纸片风格。用户明确选择其他风格时按其要求，不强加此体系。

## 先建立材质，再扩展镜头

用开场、机制解释、数据对照 3 类代表画面完成真实合成与关键动作预览，在 frame.md 记录纸基底、物件表面、边缘、阴影、印刷处理及图层顺序。查看原生帧和约 540px 小图，自主纠正后扩展全片；已授权全片时不另设用户审批。

| 层次 | 实现与可见结果 |
|---|---|
| 纸基底 | 有纤维/颗粒及细微色差的纸面；纹理尺度在原生帧可信，小图保持纸感，不变成脏点或摩尔纹 |
| 剪贴物件 | 主体纸片有可辨的切边或撕边、纸色差、硬偏移阴影和实际叠压；少量倾斜支持拼贴，不能让所有卡片随机歪斜 |
| 印刷表面 | 油墨有克制的不均匀或套印感；半色调局部用于图像/留白/强调区域，不把文字和细图线磨损到难读 |
| 标记与动作 | 黄色保留强调含义，可用马克笔边缘；纸片拍入、遮罩划线、纸页接力具有短促落定及前后层关系，动作结束后稳定阅读 |

实现可选本地纹理资产、CSS/SVG 或混合；先按 hyperframes-registry 搜索可用组件。随机纹理固定种子，动画遵守可 seek、确定性合同。缓存生成资产，避免昂贵运行时逐帧滤镜。不要仅在视频上盖噪点来冒充物件材质。

## 合成层必须实际可见

逐镜检查最上层不透明背景：全屏 SVG/图片/容器若有实心底，会盖住下面的纸纹。移除重复底色、在正确层合成纸底，或把纹理装配进该画面；不能只检查 CSS 声明、文件存在或底层截图。对象表面纹理应受自身轮廓裁切，阴影随对象移动；遮罩、放大、转场和新子合成也须保留材质。

精确文字、数字、数据和关系图仍由代码控制。定量条长、轴线、端口、连接和标签位置不得因“手作感”随机变形。保留清晰的数据层，优先在底材、外围剪边、插图和非数据区域表达材质；不为满足清单给每个图元增加阴影或半色调。

## 风格验收与证据

每场保留当前合成的原生帧、小图与关键动作片段，逐镜复查新增不透明层及材质一致性。静帧确认纸面可见、切边/叠压/阴影属于正确物件，动态确认入口、超调、落定和转场不脱层、不闪烁。原生帧看颗粒，小图看层次和整体纸片感；小图不要求每粒纤维可见。

**阻断风格验收**：承诺纸面却只有奶油平底；纸纹被不透明画面盖住；仅少数插图有纸感而主体全片是平面 UI；只添加全屏噪点；以素材存在、技术检查通过或旧版封面代替当前成片证据。先纠正并在同一时点复查，不能以“快交付”“已经渲染”放行。风格缺失应记录为待修复，更新技能本身不证明旧片已修复。

记录实际查看的版本、场景、时间、问题和修正前后证据。程序检查只能辅助，不能宣称能自动判定审美或材质真实感。
