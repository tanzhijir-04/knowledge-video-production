# 音乐方向与场景库

供制作时按选题挑选3–4种差异明确的候选，不是要求全片轮流使用所有风格。以下是编配建议，不是已存在、已试听或已授权的曲目。根据实际旁白语速、剪辑密度及听感调整，不能用流派名称替代真实试听。

| 风格/编配 | 适合选题与场景 | 剪辑和声音处理 |
|---|---|---|
| Funk / 器乐Funk | 数码消费、产品演化、拆开设备、反直觉小知识；实物剪贴连续登场 | 切分贝斯、短吉他和干鼓；动作可跟重音，别让每个字都卡点；铜管避开人声密集段 |
| Jazz-funk | 科技史、设计史、标准之争、旧广告或产品年代对照 | 电钢琴、贝斯与克制铜管；适合有层次的拼贴，复杂独奏留给无旁白间隙 |
| Boom-bap Hip-hop（器乐） | 拆营销话术、账单、价格、规格、证据标注与观点反转 | 稳定鼓点、短动机；军鼓避免与辅音争抢，不能把采样风格当成采样授权 |
| Lo-fi Hip-hop | 桌面实验、个人体验、慢一点的操作说明与温和回扣 | 柔软电钢琴、轻鼓；长段避免过于昏沉，黑胶噪声不能盖住语音 |
| Instrumental Hip-hop / Jazz-hop | 城市设备、陌生人的手机、无线网络和生活科技 | 松弛律动配稀疏爵士和声；兼顾亲近与推进，地图和记录变化可借节拍组织 |
| 轻量Trap器乐 | 性能对决、速度、芯片跑分、短促的强对比段落 | 节制808与踩镲密度；更适合局部加速，长篇解释避免持续轰低频和密集滚奏 |
| Breakbeat | 数据包接力、物流、网络路径、流程加速、多个环节串联 | 碎拍推动关系变化；转入关键定义时减薄，避免剪辑为跟鼓而破坏因果 |
| UK Garage器乐 | 移动支付、城市连接、平台服务、轻巧的现代生活观察 | 弹跳切分与轻低频；人声切片若含歌词或抢旁白则去掉，保留稀疏版本 |
| Disco / Nu-disco | 产品年代快切、消费热潮、发布会文化、轻松片头 | 稳定舞曲律动、明亮贝斯；避免整片像广告，证据段减去主旋律与厚重鼓组 |
| Soul / Neo-soul器乐 | 科技与人的关系、隐私选择、使用体验、人物段落 | 温暖和弦、柔和贝斯和松弛鼓；少旋律争抢，不用抒情铺垫替代真实论证 |
| Jazz小编制 | 日常观察、误解澄清、设计细节、轻巧幽默 | 低密度鼓刷、拨弦贝斯与短钢琴；避免繁忙即兴和刻意滑稽的强调 |
| Bossa Nova | 生活小物、充电习惯、桌面或家庭场景、平静说明 | 轻吉他与柔和打击；适合舒展节奏，不用于急迫风险或强冲突论证 |
| Minimal House / Downtempo | 系统结构、稳定流程、设备循环、数据对比 | 简洁重复脉冲便于长段混音；关键结论可抽掉鼓，避免无变化的循环疲劳 |
| Electro / 复古合成器 | 计算机史、存储、早期游戏机、数字接口演化 | 清楚的电子音色与少量琶音；复古是叙事语境，不默认霓虹赛博视觉 |
| Minimal Electronica | 协议、加密、定位、信号转换、不可见机制图解 | 稀疏脉冲、短合成器动机；留出解释空间，不将所有技术问题做成悬疑 |
| Ambient / 氛围电子 | 空间尺度、基础设施、缓慢推演、安静结尾 | 宽松持续音和极少节拍；注意低中频遮蔽，适时停奏而非始终铺底 |
| 木质打击 / 拨弦编辑配乐 | 概念拆分、分类、纸张标记、逐项验证 | 清楚短音与留白；避免每次转场都配相同弹跳和点击，防止幼儿科普感 |
| 克制调查配乐 | 隐私风险、争议证据、利益链条、待解问题 | 稀疏脉冲与低调音色，随证据推进；不靠恐怖音效暗示尚未证明的危险 |
| Chamber Minimalism / 室内乐极简 | 标准建立、历史回望、较严肃的机制推演、结论 | 小编制钢琴/弦乐短型；避免史诗高潮和不断抬升情绪，须保留编辑式清晰度 |
| 无配乐 / 仅现场感与音效 | 关键数字、决定性证据、一次操作失败、需要观众思考的停顿 | 真实或明确设计的声音承担注意力；不要用假设备提示声冒充实验结果 |

## 按段落选择声音密度

- 开场提问：用短动机和少量律动迅速建立气质；不必从第一帧放满音乐。
- 实物揭示/拼贴蒙太奇：Funk、Boom-bap、Breakbeat等可以推动动作；长度按信息量而非强行凑完整乐句。
- 机制讲解：优先同曲稀疏段、减配或分轨版本，降低旋律密度；通常无需另换流派。
- 证据与关键数字：减鼓、抽低频或短暂停奏，让事实本身成为重点。
- 反转：停拍、切分或短音色变化即可，不自动加预告片冲击音。
- 结尾回扣：回到开场动机的简化版本，或安静结束，不规定必须温暖煽情。

## 给用户的选项格式

按当期题目提供3–4种。例如定位器选题可提供：A Jazz-hop（推荐：生活感与接力路径兼顾）；B Minimal Electronica（突出信号与机制）；C Funk（更活泼、适合剪贴节奏）；D Boom-bap（突出调查和证据）。解释听感及取舍，并允许其他风格、自带音乐、无配乐或导演决定。不能每期照抄这一组合，也不把用户提到Funk/Hip-hop理解为已经选定本片配乐。

实际候选优先器乐或人声稀疏版本；无歌词也不等于免版权。逐曲核对授权与来源，混音和转场基于实际声音，不从流派标签推断响度、速度或质量。不要许诺无法获得的分轨、生成音乐服务或曲目。
