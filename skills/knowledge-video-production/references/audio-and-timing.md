# 自然配音与实际时序

制作或修改声音时，同时执行[音效与插图密度规范](sfx-and-illustration-density.md)的音效事件选择、密度与留白、素材来源、声画对齐和混合试听要求。音效不按镜头数或标签数机械分配；该文的增益起点不替代本文件的最终混音测量。

## 制作前的音乐选择

在脚本调性明确、最终配乐尚未锁定时，主动向用户提供一次音乐方向选择。已有本期明确选择则沿用，不重复询问；只做字幕、封面等无关任务不触发。选项应按本期内容筛选3–4种，各用一句说明听感、乐器与适用段落，推荐最适合的一种，同时允许用户自带音乐、不要配乐或交由导演决定。不要将选项写成含糊的“高级、震撼、科技感”。

可从以下方向中选取，不必每次全部列出：

用户希望有Funk、Hip-hop等更丰富的具体风格。选候选时读[music-directions.md](music-directions.md)，按流派、编配与段落用途组合；下表是宽泛听感说明，不是全部音乐库。不把用户要求扩充候选当成已锁定某个流派。

| 方向 | 听感与用途 |
|---|---|
| 轻快编辑节奏 | 干燥鼓点、短促拨弦或木质打击，适合纸面拼贴、日常数码话题，轻巧但不滑稽 |
| 好奇探索 | 克制的合成器脉冲、少量敲击音色，适合提出疑问、逐步拆解机制，避免整片悬疑化 |
| 温暖叙事 | 柔和键盘、轻拨弦与疏朗节拍，适合人物经验、生活场景和结尾回扣，避免煽情盖过事实 |
| 理性电子 | 简洁电子节拍、稳定低频、留白明确，适合网络路径、数据和系统图解，避免电影预告片音墙 |
| 调查纪实 | 稀疏打击与低调持续音，适合风险、争议和证据推演，不用恐怖音效替代论证 |

选项是声音方向，不等同于已有曲目。若实际工具和授权资源可用，提供2–3段约10–20秒的真实候选试听，尽量采用同一旁白片段、相近播放响度，标明曲名/来源/授权与截取区间；无可用音频时如实说明仅为方向描述。不能声称已试听或已获授权而无证据，不为提供选项擅自调用付费服务。

用户尚未答复时继续研究、分镜、图片和配音等独立工作；临时音乐保持可替换，不宣称已最终选定。用户交由导演决定或明确要求直接完成时，自主锁定并记录理由，不新增审批关卡。全片以选定声音家族保持统一，可随叙事减薄、停奏或变化，不机械地每场换曲；不必让所有镜头持续有BGM。

在production.json的music记录所提供方向、推荐、用户选择或导演授权、实际曲目及许可证据；未选定状态保持pending。最终按真实素材更新，不能把默认配置当作已完成选择。

## 配音与时间线

从环境变量`MIMO_API_KEY`取凭据，不写进JSON、skill、日志或交付包。调用前复核当前官方文档、voice/model与资费，不能把历史限时免费当承诺。缺凭据仍推进独立画面工作。

已验证形态，使用时需按当前文档复核：

```json
{"model":"mimo-v2.5-tts","messages":[{"role":"user","content":"音色语速指导"},{"role":"assistant","content":"实际旁白"}],"audio":{"format":"wav","voice":"茉莉"}}
```

参考端点：https://api.xiaomimimo.com/v1/chat/completions 。常见返回`choices[0].message.audio.data`为base64。文档：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5 。不要发明speed参数。

指导：像理解技术的朋友面对面解释；正常日常语速、连贯略明快，逗号轻连、句尾自然换气；不每句重起腔，不播音、广告或悬疑表演，不刻意气声、逐字拖长；英文术语自然读，不为固定秒数抢读；只读assistant正文。

统一preset/指导，按句意分段，不逐句产生新角色感。先用短段检查，已批准音色不必重复问。缓存绑定原文+指导+model+voice指纹，不仅看旧WAV文件名。超时后检查结果，避免不受控收费重试。

`scripts/mimo_tts.py SCENES.json --out DIR --dry-run`可检查请求与缓存计划，不访问网络；去掉dry-run才调用。SCENES为`[{"id":"s01","text":"原文"}]`，id只允许字母数字下划线横线。音色/模型/endpoint可显式覆盖；此脚本不证明当前免费。

保留raw WAV，仅裁必要首尾空白并留换气，不拉伸语音。实际测时后加有限停顿，取整到帧率。timeline记录id、startFrame、durationFrames、voiceStartFrame、voiceFrames、原文和语音指纹；Studio与渲染读同一timeline。

ASR只帮助定位，正文保持原稿；识别可能同音错误、尾部幻觉或零时长重复，弱匹配需复核。字幕按句意拆分，编号连续、正时长、无重叠、升序、末条不超母版；包括英文数字逐字覆盖原稿。估计时间戳不冒充音素强制对齐。

音效对齐实际事件帧，不每场统一三次点击，不把解释音效说成设备提示。最终通常48kHz立体声，保留VO/MUSIC/SFX。别用门限切呼吸；底乐温和闪避、自然释放，避免短停顿抽动。音乐需原创或授权明确。

参考综合约−16 LUFS、真峰值约−1.5 dBTP留AAC余量，以实际测量/用途为准，不只引用滤镜目标。区分数值检查与试听；不能声称听过未听的声音，可提供试听但不永久卡住其他工作。
