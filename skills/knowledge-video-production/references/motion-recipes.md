# 科普视频扩展动效配方

与vox-style-animation的motion-vocabulary配合使用，保留纸面、油墨、剪贴和克制强调的语言。本文件是可复用的编排配方，不是已运行验证的组件库。实施时读取hyperframes-core及相关animation适配文档；沿用既有项目的确定性时间线。

## 先选动作的作用

揭示隐藏信息 → 遮罩揭示；改变注意对象 → 焦点切换；说明差异 → 对照展开；解释流动 → 对象传递；解释组成 → 拆解重组；查看细节 → 局部放大；追踪经过 → 路径追踪；说明前后变化 → 状态替换。没有对应的知识变化时，可以保持静止。不要每场轮换特效来制造多样性。

## 共同的速度曲线规则

以下秒数、比例是待预览调整的起点，不是客观最优值。按位移距离、主体尺度、文字长度和旁白调整，锁定实际FPS后将事件边界量化到帧。

| 运动意图 | 默认曲线 | 使用条件 |
|---|---|---|
| 出现并落定 | `power3.out`，强调入口可选`expo.out` | 开始快、末端慢；到阅读状态后停稳 |
| 两个位置间搬移 | `power2.inOut` | 起止都静止；不能用在需匀速通过的路径接缝 |
| 离开/遮挡后切换 | `power2.in`或`power3.in` | 加速离开，确认出画或被遮挡后再切内容 |
| 匀速过程 | `none` | 路径进度、时间刻度等；若表达物理速度，路径弧长与时间也要一致 |
| 轻微落纸回弹 | `back.out(1.15)`作为起点 | 只用于有余量的剪贴物；标注、数据、节点与密集图解默认无超调 |
| 手绘笔画/背景纹理 | 有限`steps` | 阶梯感不应用到可读文字、主体或整幅相机运动 |

本用户路线不照搬上游节点示例的`back.out(1.6)`：回弹必须有语义、留出超调空间并实际检查。`back`参数不是超调百分比，不能据此声称已满足净距。

同一对象同一属性的有效tween不能重叠；定位层与动画层分开。连续通过的运动使用同一进度或匹配接缝速度，不能把多个减速到零的片段拼成走走停停。需要停顿时明确安排停顿。不同属性或不同层可以有意同时运动，但不能造成阅读竞争。

所有关键状态由时间线显式给定，支持从任意帧直接seek。禁止依赖前一帧累积、实时钟或只触发一次的回调来构建画面。初始化时确定几何/路径，不能在tween更新中测DOM再改布局。通过内部wrapper的transform、opacity、SVG绘制或确定性遮罩实现，框架保留clip可见性控制。

## 1. 遮罩揭示：信息从被遮挡到可见

- **用途**：展示档案局部、结构内部或新增证据；不自动意味着时间先后或因果。
- **编排**：目标先在最终位置排好 → 遮罩沿语义方向展开0.45–0.7秒，`power2.out` → 全部可读后保持，保持时长依内容确定。
- **实现要点**：移动裁切窗口或确定性SVG遮罩，内容本体保持几何稳定；纸边可以作为揭示边界，不压扁文字模拟展开。
- **验收**：中途裁切不能制造错误数字；作为证据引用前须完整显示必要上下文。检查起始、中段、完全展开和直接seek。

## 2. 焦点切换：从整体转向一个对象

- **用途**：讲解复杂图中的当前环节，保留整体方位。
- **编排**：目标标记在0.25–0.4秒内显现，`power2.out`；非焦点层降低视觉权重；讲解结束后0.25–0.4秒恢复或切到下一个对象。
- **实现要点**：优先增加局部高亮、轮廓或纸色遮罩；必读对象不被整体压暗到不可读。先不缩放布局，避免为了强调让标签重排。
- **验收**：小图中只有一个主要焦点；未被强调的必要连接仍能追踪。颜色不应额外暗示“失效/错误”；连续切换不留下累计变暗状态。

## 3. 对照展开：在共同基准上看差异

- **用途**：前后状态、两种机制或同口径数据比较。
- **编排**：先呈现共同基准 → A与B在0.5–0.8秒内展开，`power3.out`；可按讲解错开约0.1–0.2秒 → 差异标记在双方可见后出现。
- **实现要点**：共用对齐轴、单位与有意义的比例；左右或上下皆可，不固定卡片模板。用外层运动保持最终版面，内容不要被横向挤压。
- **验收**：并列状态有足够阅读时间；颜色、尺度及出现顺序不制造未经支持的优劣或因果。中途不把一半数据显示成完整结论。

## 4. 对象传递：沿通道解释流动

- **用途**：请求、消息、能量或材料从源到目标；明确它是过程示意还是有真实速度的数据。
- **编排**：源/目标与路径先建立 → 代表物沿路径运行约0.6–1.2秒 → 到达后以0.15–0.3秒的标记变化确认接收；示意传递默认匀速进度或有意的起停。
- **实现要点**：从固定路径进度派生代表物坐标；多段路径连续通过时不在每段重新缓入缓出。标签可在源端解释，避免携带一段小字高速移动。跨端口的隐藏/显现使用明确遮罩。
- **验收**：源、通道、目标可追踪；没有穿入无关对象、半路闪现或接收先于到达。不把匀速参数直接宣称为匀速像素运动；必要时按弧长采样。

## 5. 拆解重组：解释组成与层次

- **用途**：说明内部部件、职责划分或系统层次。
- **编排**：整体先可辨认 → 部件沿各自方向分离0.6–0.9秒，`power2.inOut` → 标签在部件接近落定后出现；需要重组时使用已定义的归位路径。
- **实现要点**：预先准备独立部件及装配/展开两套锚点，从同一时间进度插值；标签与部件绑定。拆解是示意时要避免暗示错误真实结构。
- **验收**：展开状态无交叉误读、关键遮挡或出画；重组关系与初始一致。只有完整位图时先取得部件，不把整图伸缩描述为拆解。

## 6. 局部放大：从全局进入细节

- **用途**：检查接口、源材料上的数字或局部机制。
- **编排**：先标出目标 → 相机或局部视窗在0.6–0.9秒内移动并放大，`power2.inOut` → 稳定停留供阅读；必要时按相同锚点返回。
- **实现要点**：目标锚点在同一坐标空间，照片与附着标记共用变换。镜头终态先构图，再求起止变换；保留足够素材分辨率。放大倍数按任务决定，不默认每场推近。
- **验收**：放大后仍能辨认细节属于哪个对象；没有糊字、裁掉关键上下文或标签脱离主体。检查相机中点和极值，不只看终点。

## 7. 路径追踪：解释先后与经过

- **用途**：路线、步骤、信号传播方向；与对象传递不同，这里重点是路径如何建立。
- **编排**：端点先可见 → 按方向绘制路径约0.5–0.9秒 → 到达转折或目标时引入对应标记；整体节奏按讲解分段。
- **实现要点**：SVG路径长度预先取得，通过dash进度绘制；`power2.inOut`适合一次起止的示意笔画，表达持续传播则优先`none`。箭头随已画到的位置出现，不能提前暗示已到达。
- **验收**：路径交叉不被读成汇合，绘制方向与语义一致，线不穿字。若路径长度映射真实时间/距离，不能让纯审美ease改变数据含义。

## 8. 状态替换：保留对象，改变状态

- **用途**：等待→完成、旧规则→新规则、受阻→可用。
- **编排**：保持对象身份和主锚点 → 旧状态在0.15–0.25秒内退出 → 新状态在0.25–0.4秒内进入，`power2.out`；必要时用局部纸片/遮罩覆盖替换点。
- **实现要点**：文本保留明确的前后两层及各自状态，避免中间出现错误拼字或半个数字；同一对象内部替换，不无理由重进整场。交叉淡化仅在重叠期间不会混读时使用。
- **验收**：状态变化原因在脚本/动作中可解释；没有新旧文字叠读、双重状态、错误中间值或音画先后颠倒。不用无限闪烁表达等待。

## 使用与验收

将选用配方、旁白触发点、实际起止帧和例外记入已有分镜/时间线，不新增重复文档。先实现能读懂的最终布局，再按需要组合动作；主动作进行时降低辅助动作的竞争。

查看真实片段，并在入口、最大位移/超调、关系交叉、落定与转场抽帧。正向播放与乱序直接seek应在相同时间得到相同状态；修改曲线/时间后复查附件、路径和相邻转场。审查依据是visual-acceptance-contract.md，未实际渲染不得宣称这些配方已通过运动验收。
